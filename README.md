# நூல் மீட்பு (Nool Meetpu)

நூற்றாண்டு பழைமையான தமிழ் நூல்களையும் ஓலைச்சுவடிகளையும் செயற்கை நுண்ணறிவின் கற்பனைச் சொற்கள் (Zero Hallucination) இன்றி மீட்டெடுக்கும் உயர்தர எண்மியக் கட்டமைப்பு.

## முக்கிய சிறப்பம்சங்கள்

1. **முழுமையான தமிழ் இடைமுகம்**: பயன்பாட்டின் அனைத்துப் பொத்தான்கள், தலைப்புகள், குறிப்புகள் மற்றும் வழிகாட்டிகள் தூய தமிழ் எழுத்துருவில் மட்டுமே வடிவமைக்கப்பட்டுள்ளன.
2. **இரண்டு நுழைவு வாயில்கள்**:
   - **பொதுமக்கள் நுழைவு**: நூல்கள் தேடல், நேரலை நிழற்படக் கருவி வழியே படம் பிடித்து பதிவேற்றுதல், திருத்தப் பரிந்துரை செய்தல்.
   - **அதிகாரிகள் நுழைவு**: நூலகர், திருத்துநர், தலைமை மேற்பார்வையாளர், நிர்வாகி ஆகிய நான்கு நிலை அதிகார வரம்புகளுடன் கூடிய விரிவான ஆய்வரங்கம்.
3. **நேரலை நிழற்படக் கருவி (Live Camera)**: ஆவணச் சட்டக வழிகாட்டி மற்றும் தானியங்கிப் படம் எடுக்கும் வசதி.
4. **தமிழ்நாட்டு வரலாற்று வரைபடம்**: தஞ்சாவூர் பெரிய கோவில் மற்றும் சரஸ்வதி மகால், மாமல்லபுரம், மதுரை தமிழ்ச் சங்கம், கீழடி உள்ளிட்ட 8 முக்கிய சுவடி மையங்களை வரைபடத்தில் கிளிக் செய்து வரலாற்று விவரங்களை வாசிக்கும் ஊடாடும் தளம்.
5. **புத்திசாலிப் படச் சீரமைப்பு**: மூலப்படம் ↔ சீரமைத்த படம் இழுவை ஒப்பீடு, கறை நீக்கம், மங்குதல் மீட்பு, வடிவ நிரப்பு (Tamil Glyph Template Matching).
6. **கட்டுப்பாட்டுத் திருத்த இயந்திரம்**: செந்தமிழ் சொற்களஞ்சியம், தற்காலத் தமிழ், இந்நூல் சொற்கள் ஆகிய மூன்று அடுக்கு சொல்லடைவுகளிலிருந்து மட்டுமே திருத்தங்கள் ஏற்கப்படும். அழிக்கப்பட்ட எழுத்து சோதனை (Deleted Glyph Test) பொத்தான் இணைக்கப்பட்டுள்ளது.
7. **நான்கு பலகை கூட்டு மதிப்பாய்வு அரங்கம்**: மூலப்படம், மேம்படுத்திய படம், 4 எழுத்துணரி கருதுகோள்கள், இறுதி உரை ஆகியவை ஒத்திசைக்கப்பட்ட பார்வை. தமிழ்99 விசைப்பலகை வசதி.
8. **பாதுகாப்பு & காப்பகம்**: மாற்றவியலா தணிக்கைப் பதிவு, கையொப்பமிட்ட மாதிரிகள், முழுவதும் தனிமைப்படுத்திய பயன்முறை (Air-gapped mode), காப்பக வடிவ PDF/A, TEI XML, எளிய உரை பதிவிறக்கம்.

## பயன்பாட்டை இயக்குவது எப்படி?

1. சார்புகளை நிறுவ:
   ```bash
   npm install
   ```

2. மேம்பாட்டு வழங்கனைத் தொடங்க:
   ```bash
   npm run dev
   ```

3. திட்டத்தை உருவாக்க (Build):
   ```bash
   npm run build
   ```

4. இணைய உலாவி வழியே அணுக:
   உலாவியில் `http://localhost:3000` முகவரியைத் திறந்து பயன்பாட்டை இயக்கலாம்.
